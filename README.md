<h1 align="center">Token Strategist</h1>

<p align="center">
  Design and deploy tokens on Base via Bankr CLI.<br/>
  Evaluates concepts against five market forces, sets up wallets, handles fee splits, and executes launches.
</p>

## Install

1. Install [OpenClaw](https://docs.openclaw.ai/install)
2. Tell your agent to install this skill:

```
Install the skill from https://github.com/BankrBot/token-strategist
```
